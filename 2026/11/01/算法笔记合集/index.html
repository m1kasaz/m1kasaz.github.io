二分查找

搜索旋转排序数组（LeetCode 33）

对比红蓝区间染色，这里的定义是：

  • 红色（right 控制）：下标 i 满足「nums[i] 应当排在 target 及其右侧」。换句话说，从 target 应当出现的下标开始，一直到 n-1，全部是红色。
  • 蓝色（left 控制）：下标 i 满足「nums[i] 应当排在 target 的左边」。也就是 0 .. (target 应当出现的下标 - 1)，全部是蓝色。

不用内置函数求算术平方根

题目描述： 给你一个非负数 x，计算并返回其算术平方根，结果要求保留一位小数（向下截断）。注意： 不允许使用任何内置开方函数（如 math.sqrt()、pow(x, 0.5) 等）。

  • 示例 1：输入 x = 4，输出 2.0
  • 示例 2：输入 x = 8，输出 2.8

笔记翻倍后的最大子段和

题目描述： 博主小红发布了一组共 n 篇笔记，每篇笔记有一个初始热度值 a_i（正数表示受欢迎，负数表示反响不佳）。

运营团队允许小红执行一次推流加倍操作：选择一个连续笔记区间 [l, r]（1 ≤ l ≤ r ≤ n），将该区间内所有笔记的热度值变为原来的两倍。当然，他也可以选择不执行此操作。

操作结束后（或不操作），小红想知道连续笔记的最大热度总和是多少。注意：所选子段不能为空，至少包含一篇笔记。

状态 含义 第 i 个数的贡献
dp[i][0] 子段还在翻倍区间前面（没翻倍） a[i]
dp[i][1] 子段正在翻倍区间里 2*a[i]
dp[i][2] 子段已经越过翻倍区间（翻倍结束） a[i]

约束：

  • 1 <= nums.length <= 10^4
  • -10^4 <= nums[i] <= 10^4

思路：

  • 最大频次小于或等于 n/2 下取整 即可满足题意
  • 按照字典序重新排 kv，字典序小的优先

下载器与译码器的最优调度

题目描述： 有一个下载器和一个译码器。现共有 n 个任务，第 i 个任务的下载时间为 a_i，译码时间为 b_i。

每个任务都必须先由下载器完整地下载，之后才能由译码器译码。同一时刻，下载器最多只能处理一个任务，译码器也最多只能处理一个任务；但下载器与译码器可以同时工作——即下载器下载某个任务时，译码器可以译码另一个已经下载完成的任务。

你可以任意安排这 n 个任务的执行顺序（每个任务都执行恰好一次）。求完成所有任务所需的最短时间（即从时刻 0 开始，到最后一个任务译码完毕的时刻）。

给定一个只包含字符 'A' 和 'B' 的字符串 s，找出其中 A 和 B 数量相等的最长连续子字符串的长度。

约束：

  • 1 <= s.length <= 10^5
  • s[i] 只为 'A' 或 'B'

一次免费通行的最短路径

给定 n 个节点（编号 0 到 n-1）和若干条带权无向边，求从节点 0 到节点 n-1 的最短路径。你有一次机会可以将经过的某条边的权重视为 0（即免费通行一次）。返回使用该机会后能得到的最小路径权重。

约束：

  • 2 <= n <= 10^4
  • 0 <= edges.length <= 10^5
  • edges[i] = [u, v, w]，其中 1 <= w <= 10^6
