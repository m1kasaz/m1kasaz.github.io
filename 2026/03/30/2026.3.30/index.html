230. 二叉搜索树中第 K 小的元素

给定一个二叉搜索树的根节点 root ，和一个整数 k ，请你设计一个算法查找其中第 k 小的元素（k 从 1 开始计数）。

思路：遍历顺序肯定是中序，才能用上搜索树的性质。

  1. 全局记录答案。
  1. 向上递归答案。

114. 二叉树展开为链表

给你二叉树的根结点 root ，请你将它展开为一个单链表：

  • 展开后的单链表应该同样使用 TreeNode ，其中 right 子指针指向链表中下一个结点，而左子指针始终为 null 。
  • 展开后的单链表应该与二叉树 先序遍历 顺序相同。

思路：

想象一个简单的树：

  1. 右子树 (5)：5.right = prev(null), prev = 5。
  2. 左子树 (2)：2.right = prev(5), prev = 2。
  3. 根节点 (1)：1.right = prev(2), prev = 1。

所以，我们应该以右左根的顺序遍历二叉树，让当前节点的右子树指向pre，然后更新pre。

155. 最小栈

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

  • MinStack() 初始化堆栈对象。
  • void push(int val) 将元素val推入堆栈。
  • void pop() 删除堆栈顶部的元素。
  • int top() 获取堆栈顶部的元素。
  • int getMin() 获取堆栈中的最小元素。

思路：维护一个最小栈，只有元素<=栈顶才push，用了==比数值，尿了

致命问题：对象比较 vs 数值比较

在 pop() 方法中，你使用了 == 来比较 stk.peek() 和 min_stk.getFirst()：

Java

  • 原因：stk.peek() 和 min_stk.getFirst() 返回的都是 Integer 对象，而不是基本类型 int。
  • 后果：在 Java 中，Integer 对象在 -128 到 127 之间会有缓存，使用 == 比较能通过。但一旦数值超过这个范围，== 比较的就是内存地址而不是数值。
  • 修正：必须使用 .equals() 或者先拆箱为 int。
